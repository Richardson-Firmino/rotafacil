ROTAFÁCIL — COMO ENVIAR AO GITHUB DO ZERO

ESTE PACOTE JÁ VEM ORGANIZADO:
- README.md (com sumário e texto revisado)
- docs/arquitetura-aws.png (diagrama usado no README)
- assets/README.md (descrição da pasta de materiais)

PARTE 1 — BAIXAR E EXTRAIR
1. Baixe o arquivo ZIP enviado junto com estas instruções.
2. No Windows, abra a pasta Downloads.
3. Clique com o botão direito no ZIP e escolha "Extrair Tudo".
4. Abra a pasta extraída "RotaFacil-GitHub-Pronto".
5. Confira que você vê README.md e as pastas docs e assets.

PARTE 2 — ENVIAR PARA O REPOSITÓRIO EXISTENTE
1. Abra https://github.com/Richardson-Firmino/rotaf-cil
2. Se você já enviou arquivos antes, não precisa criar outro repositório.
3. Para colocar os arquivos na página principal, entre na página inicial do repositório (não entre na pasta antiga).
4. Clique em "Add file" e depois em "Upload files".
5. Abra a pasta "RotaFacil-GitHub-Pronto" no computador.
6. Selecione README.md e as pastas docs e assets e arraste-os para a área de envio do GitHub.
   Dica: arraste o conteúdo de dentro da pasta extraída, não a pasta "RotaFacil-GitHub-Pronto" inteira.
7. Espere os arquivos carregarem.
8. Em "Commit changes", deixe a mensagem sugerida ou escreva: "Atualiza documentação do RotaFácil".
9. Clique em "Commit changes" para concluir.

ATENÇÃO:
- Se o GitHub avisar que README.md já existe na raiz, confira se está substituindo/atualizando o arquivo correto.
- Não apague a pasta antiga até confirmar que a nova versão aparece corretamente na página principal.
- O README usa o caminho docs/arquitetura-aws.png. Mantenha a pasta docs e o nome do arquivo exatamente assim.
- Depois de salvar, abra https://github.com/Richardson-Firmino/rotaf-cil para verificar se o título, o sumário e o diagrama aparecem.
